# TIME CLASH – mehrsprachige Songs

Dieser Ordner enthält die MP3-Versionen der offiziellen TIME-CLASH-Songs für den Musikplayer auf der öffentlichen Website und in der BetInsight-App.

## Hochladen

Auf GitHub im Ordner `assets/time-clash/audio/` **Add file → Upload files** wählen und alle MP3-Dateien hier hochladen.

Vorhandene Dateinamen bitte zunächst **nicht eigenmächtig ändern**. Nach dem Upload werden die Dateinamen den folgenden Sprach-/Länder-Versionen zugeordnet:

- Deutsch (Deutschland)
- English (United Kingdom)
- English (International)
- Português (Brasil)
- Português (Portugal)
- Español (España)
- Español (Argentina)
- Italiano (Italia)
- Français (France)
- Nederlands (Nederland)
- Weitere Versionen nach Bedarf

Die Originale sind noch nicht sämtlich hochgeladen. Ein gemeinsamer Player lädt die jeweilige MP3 erst, wenn jemand auf Play klickt. Die Länderauswahl wird unabhängig von der Seitensprache angeboten.

**Wichtig:** Keine automatisch startende Musik und keine Änderung an der TIME-CLASH-Spiel-Engine.
