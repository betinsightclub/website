2. 適用範圍及一般原則

本隱私權政策適用於 LucMedia LTDA 營運或發起的 BetInsight 公開網站、註冊、會員專區、個人檔案、預測解鎖、Units 管理、推薦及合作夥伴功能、Premium 功能、錢包管理、Units 交換平台及相關支援與付款流程。

個人資料僅在提供平台、履行合約及付款、管理使用者帳戶與合作夥伴歸屬、保障系統安全或遵守法定義務所需的範圍內處理。

依使用者所在地，可能適用巴西一般資料保護法（LGPD）、在其適用範圍內的歐盟一般資料保護規則（GDPR）及其他強制性隱私法規。

3. 造訪網站時的資料

造訪網站時可能處理技術上必要的存取資料，包括 IP 位址、日期及時間、請求的頁面或檔案、瀏覽器與裝置資訊、來源網址以及技術錯誤與安全資料。

處理目的為提供網站、維護技術穩定性、分析錯誤、防止濫用及保障平台安全。

4. 註冊、使用者帳戶及會員專區

註冊及使用 BetInsight 帳戶時，可能處理電子郵件、如有提供的姓名、內部使用者與帳戶識別碼、技術存取與安全識別碼、推薦碼、推薦人及網路歸屬、會員及 Premium 狀態、有效期間及權限、Units 餘額、來源及相關變動、已解鎖預測及相關交易或歷史資訊。

這些資料用於提供帳戶、管理存取權限、正確分配 Units、執行解鎖、驗證網路及 Premium 資格並維持可追溯的平台紀錄。

5. 推薦、合作夥伴及聯盟行銷資料

BetInsight 使用個人推薦碼，使註冊可歸屬於推薦合作夥伴。可能處理推薦碼、推薦人歸屬、網路層級、歸屬時間及衍生的推薦或佣金資料。

使用外部廣告或聯盟連結時，可能向第三方提供活動識別碼、推薦參數或類似追蹤資訊。目的網站的後續處理適用該第三方自身的隱私條款。

6. Units、預測及內部交易資料

為正確結算及追溯，可能處理購買、贈送或透過推薦取得的 Units 資料，包括購買或來源批次、剩餘餘額、消耗、解鎖、保留、轉移、出售核准及歷史紀錄。

解鎖預測時，可能儲存使用者參照、預測識別碼、時間、Unit 價格及已消耗 Units 的來源，以提供服務、結算、防止重複入帳及保存紀錄。

7. 付款及加密貨幣

付費服務可能處理付款及交易資料。依付款方式，資料可能包括金額、法幣或加密貨幣、網路、付款狀態、付款及交易識別碼，以及錢包或區塊鏈資訊。

購買服務時可能使用外部支付服務商。若使用 Plisio 或其他加密貨幣支付服務商，該服務商依自身法律及隱私條款處理付款所需資料。

區塊鏈交易可能公開且永久可追溯。已寫入公開區塊鏈的資料原則上無法由 BetInsight 事後刪除或修改。

8. 錢包、Units 交換平台及會員間交易

使用者儲存錢包或使用交換平台功能時，可能處理錢包地址、網路、報價資料、保留狀態、買賣雙方歸屬、金額、付款指紋、TXID 及區塊鏈確認資料。

會員錢包之間直接付款時，BetInsight 使用必要資料進行交易歸屬、驗證及後續內部 Units 轉移。區塊鏈付款本身在 BetInsight 內部資料庫之外進行。

9. Premium、網路佣金及提領

Premium 及 Premium Plus 功能可能處理方案、啟用、有效期間、續約、寬限或審核狀態、網路資格、佣金產生及狀態和提領資料。

提領申請可能處理提領金額、錢包地址、網路、最低金額、接受的費用、核准狀態、提領識別碼及 TXID，以驗證資格、防止詐欺、執行提領及保存紀錄。

10. 語言、推薦碼及本機儲存

BetInsight 可能使用技術上必要的瀏覽器儲存機制，例如 Local Storage 及必要的 Cookie，尤其是儲存所選語言及推薦碼，以便切換頁面時保留設定。

受保護的會員專區亦可能使用技術上必要的工作階段或存取資訊。

11. 技術服務提供者

營運、託管、自動化、註冊、資料管理及付款可能使用外部服務提供者，視功能包括用於公開網站的 GitHub Pages 及 GitHub/Microsoft、用於註冊登入及會員功能的 systeme.io、用於自動化及伺服器端檢查的 Make、用於內部資料儲存及管理的 Google 服務（尤其 Google Sheets）、實際付款使用的 Plisio 等加密貨幣支付服務商，以及用於驗證公開交易資料的區塊鏈及基礎設施服務。

11a. Google Blogger、Blogger API 與自動發布

LucMedia LTDA 透過 Google Blogger 營運自有編輯資訊服務，尤其是 BetInsight Magazine，以及其他適用的公司自有部落格。BetInsight Blogger Automation 正在建置，用於管理這些部落格、建立及編輯草稿、發布多語言內容及檢查發布狀態。

為此使用官方 Blogger API 與 OAuth 2.0。經具備權限的 Google 帳戶持有人明確授權後，可能處理部落格及文章識別碼、文章內容、分類、作者資訊、發布時間、技術狀態資料及存取所需的 OAuth 權杖。本應用程式並非用於存取部落格讀者的私人資料。

存取權杖必須安全儲存並限制存取。API 資料僅用於已授權的管理功能，並依需要儲存在受保護的系統中。這些資料不會出售、不會用於個人化廣告，也不會用於訓練通用人工智慧模型。僅在授權功能所需且符合 Google 政策及適用法律時才會分享；Google 會接收 API 呼叫及發布所需的資料。

Google API 資料的使用遵守 Google API 服務使用者資料政策，包括適用的限制使用（Limited Use）要求。

可隨時透過 Google 帳戶設定 撤銷授權。授權終止後，必須刪除不再需要的存取權杖與 API 個人資料，法定保存義務另有要求者除外。刪除申請可寄至第 1 節所列電子郵件。已發布文章可能維持公開，直到另行移除。

12. 處理目的及法律依據

依適用法律，處理主要基於締約前措施及履行合約、遵守法定義務、保障平台安全與正常運作的正當利益，或依法需要時取得的同意。

13. 接收者及資料揭露

不出售個人資料。僅在提供服務、處理付款、技術營運、防止詐欺、履行法定義務或保障正當利益所需且合法時揭露資料。

使用者前往外部體育博彩、賭場、付款、錢包、VPN 或其他合作夥伴服務時，可能與該第三方建立獨立法律關係。

14. 國際資料傳輸

LucMedia LTDA 位於巴西。技術服務提供者也可能在不同國家營運，因此個人資料可能在國際間處理或傳輸。

依法需要時，採用適當的合約、組織或其他法定保護措施。

15. 保存期間

個人資料原則上僅保存達成相關目的所需的期間。若有法定保存、舉證、稅務或其他義務，或為提出、行使或防禦法律請求所需，可能延長保存。

技術及財務交易歷史可能因安全、結算及舉證目的保存較長期間。

16. 使用者權利

依適用資料保護法，使用者可能享有確認處理、查閱、更正、刪除、匿名化、封鎖或限制處理、資料可攜、反對處理、撤回同意及取得接收者或揭露資訊等權利。

申請可寄至 betinsight.club@gmail.com。向主管監督機關提出申訴的權利不受影響。

17. 安全

LucMedia LTDA 採取適當技術及組織措施，保護個人資料免於遺失、竄改、未經授權的存取及濫用。

18. 未成年人

由於 BetInsight 提供體育博彩相關資訊且可能連結至博彩服務商，原則上僅面向成年人。

TIME CLASH – 模擬及歷史資料

使用 TIME CLASH 時，已完整結束的模擬會被儲存以提供全域歷史與統計。資料可能包括日期及時間、匿名對戰或工作階段識別碼、所選球隊及年代、系列長度、個別結果、進球球員、助攻及其他模擬事件。訪客資料不會連結至個人 BetInsight 檔案，除非功能所需。

已註冊使用者的資料亦可能連結至帳戶，以提供個人歷史、Clash Points、統計、排行榜及適用的獎勵功能。公開比賽報告不應顯示可直接識別的帳戶資料。本政策所述權利及一般保存與刪除原則均適用。

19. 本政策的變更

法律要求、技術系統、服務提供者或 BetInsight 功能發生變更時，本隱私權政策可能更新。以網站目前發布的版本為準。
