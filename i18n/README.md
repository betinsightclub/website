# Central i18n (development foundation)
Existing production pages are intentionally untouched. Registry uses existing BetInsight codes including pt and zh-tw. Add a locale by adding its registry entry and dictionary, matching the default dictionary keys. Use data-i18n for plain text; complex markup, forms, metadata, server rendering, localized URLs and email templates need separate migration adapters. Preserve existing route URLs and query parameters. Next: migrate shared footer and tipster page, test all eight languages, compare existing routes and SEO, then expand using the confirmed MCT language list.
